# Universal DKP releases

Downloads for Universal DKP, a DKP loot system for World of Warcraft: Forever. The source code isn't published here.

- **Addon:** `UniversalDKP-<version>.zip` on the `addon-v*` releases. Unzip it into `World of Warcraft/_forever_/Interface/AddOns`.
- **Uploader:** `udkp-tray.exe` (the notification-area app, which updates itself from these releases) and `udkp-uploader.exe` (the command-line version) on the `uploader-v*` releases.
- **Server:** the web app's Docker image, `ghcr.io/nickspinosa/udkp-web`.

The uploader builds are unsigned, so on Windows click **More info** then **Run anyway** on the SmartScreen prompt.
